# Primary sources

Research reviewed 2026-10-11. Check local help/current vendor requirements when relevant.

- [Agent Skills specification](https://agentskills.io/specification): packaging/progressive disclosure.
- [Microsoft ping](https://learn.microsoft.com/en-us/windows-server/administration/windows-commands/ping): bounded probes/family/DF flags.
- [Test-NetConnection](https://learn.microsoft.com/en-us/powershell/module/nettcpip/test-netconnection) and [Find-NetRoute](https://learn.microsoft.com/en-us/powershell/module/nettcpip/find-netroute): TCP and selected route inspection.
- [Windows WLAN report](https://support.microsoft.com/en-us/windows/analyze-the-wireless-network-report-76da0daa-1db2-6049-d154-7bb679eb03ed): sensitive disconnect history.
- [Apple Wireless Diagnostics](https://support.apple.com/guide/mac-help/use-wireless-diagnostics-on-your-mac-mchlf4de377f/mac): supported Wi-Fi investigation; local man pages govern CLI flags.
- [NetworkManager nmcli](https://networkmanager.dev/docs/api/latest/nmcli.html): optional inspection/cached scans/secrets.
- [iputils ping](https://github.com/iputils/iputils/blob/master/doc/ping.xml) and [tracepath](https://github.com/iputils/iputils/blob/master/doc/tracepath.xml): Linux semantics/PMTU.
- [RFC 7567](https://www.rfc-editor.org/rfc/rfc7567): queueing and active queue management.
- [RFC 1191](https://www.rfc-editor.org/rfc/rfc1191) and [RFC 8899](https://www.rfc-editor.org/rfc/rfc8899): PMTU/filtering/tunnels/black holes.
- [Netflix speeds](https://help.netflix.com/en/node/306) and [Google Meet network preparation](https://support.google.com/a/answer/1279090): workload-specific requirements; verify current guidance.
