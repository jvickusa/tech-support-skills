# Tech Support Skills

## Purpose

Public troubleshooting skills associated with whyismyinternetcrap.com. Compatible agents guide users
through read-only diagnosis and produce evidence-based reports. Users may have no coding experience.

## Platform

Agent skill files for Windows, macOS and Linux. Report artifacts are Markdown or static standalone HTML.
No report-building app, backend, account, tracking, or automatic upload.

## Reports

User confirmed static standalone HTML. Agent chooses content based on the task; templates provide optional
structure rather than a required metric schema. Offer Markdown, HTML or both. HTML inherits the website's
visual identity, works offline without Python/Node, and supports browser printing and mobile reading.
Observations, hypotheses/confidence, unknowns and next actions remain visibly distinct.
